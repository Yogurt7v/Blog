My Blog Practice App
====================

Небольшое учебное приложение-блог на React/Redux со стилями на `styled-components`. В качестве бэкенда используется `json-server` на порту 3004.

Быстрый старт
-------------

Установить зависимости:

```bash
npm install
```

Запустить фронтенд (порт 3000):

```bash
npm start
```

Запустить API (порт 3004):

```bash
npx json-server --watch src/db.json --port 3004
```

```bash
npm run dev:api
```

Структура
---------

- `src/Bff` – операции и HTTP-запросы
- `src/pages/main` – главная: список постов, поиск, пагинация
- `src/db.json` – мок-БД для `json-server`


Окружение
---------

- Frontend: `http://localhost:3000`
- API: `http://localhost:3004`

Примечания
----------

- Если начальная загрузка постов падает — убедитесь, что API запущен на 3004.
- Изображения грузятся по внешним URL — требуется доступ в интернет.
